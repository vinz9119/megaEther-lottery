# Contributing

This repository contains educational blockchain and software-engineering prototypes.

## Principles

- Prefer small, understandable changes.
- Document assumptions and security boundaries.
- Do not claim deployment or testing that has not actually happened.
- Keep experiments reproducible.
- Add tests when behavior is changed.
- Avoid adding dependencies without documenting why they are needed.

## Pull requests

A useful change should explain:

1. what changed
2. why it changed
3. how it was verified
4. what remains unverified
