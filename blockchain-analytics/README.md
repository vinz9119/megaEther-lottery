# Blockchain Analytics

A research-oriented analytics project for turning blockchain activity into reproducible metrics.

## Planned metrics

- transaction counts by address
- activity by time window
- token flow summaries
- protocol interaction frequency
- concentration and retention metrics
- simple anomaly indicators

## Engineering goals

The implementation will favor deterministic data transformations, documented assumptions, and reproducible outputs.

## Status

Research prototype. No claims of production accuracy until data sources and calculations are tested.
